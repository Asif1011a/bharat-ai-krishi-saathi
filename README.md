# bharat-ai-krishi-saathi

A voice-first AI advisory system for rural farmers in India.

## Problem
Farmers lack timely, accessible, and trusted crop guidance due to literacy, internet, and smartphone barriers.

## Solution
Bharat AI Krishi Saathi enables farmers to receive hyper-localized agricultural advice through simple Tamil/Hindi voice calls using:

- Amazon Transcribe (Speech-to-Text)
- RAG with OpenSearch (Verified ICAR data)
- Amazon Bedrock (LLM Reasoning)
- Amazon Polly (Voice Response)
- Weather API Integration

## Key Features
- Voice-only interaction (No smartphone required)
- Trusted government agricultural data
- Hyper-local weather integration
- Serverless and scalable AWS architecture

## Estimated Cost
- One-time: ₹55,000
- Monthly: ₹5,500 – ₹8,000

## Architecture
Serverless, scalable GenAI system built using AWS services.
